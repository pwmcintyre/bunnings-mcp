# Security policy

When GitHub private vulnerability reporting is available, report vulnerabilities through **Security → Advisories → Report a vulnerability**. If that option is unavailable, private reporting is not configured; do not disclose vulnerability details in a public issue. See [GitHub's reporting setup guide][1].

[1]: https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository
